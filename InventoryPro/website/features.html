Product Management

Complete control over your product catalogue. Add, edit, and delete products with validation. Search by name or filter by stock status instantly.

  • Add / edit / delete products
  • Search by name or ID
  • Filter by stock status

Sales Recording

Record sales in seconds. Search and select products, enter quantity, and the system automatically calculates the total, deducts stock and generates a receipt.

  • Product search and selection
  • Live total price calculation
  • Stock validation
  • Automatic stock deduction
  • Printable and shareable receipt

Security Features

🔐
BCrypt Password Hashing
Passwords are never stored as plain text. BCrypt hashing ensures passwords are secure even if the database is compromised.
🛡️
Role-Based Authorization
Policy-based authorization enforced at controller level. Shop Assistants cannot access Manager-only pages even by typing URLs directly.
🔑
Google Single Sign-On
Login with your Google account for fast, secure access without managing a separate password.
📧
Password Reset
Secure password reset via email link. Firebase Authentication sends a time-limited reset URL.
